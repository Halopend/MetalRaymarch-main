# Threshold — Cleanup & Simplification Audit

Generated by a 17-auditor parallel sweep (15 module-scoped + 2 cross-cutting), with every
"remove this / dead code" claim re-checked by an adversarial project-wide grep before inclusion.

- **152** raw findings → **20 refuted** (false positives, dropped) → **132** verified findings.
- Behavior-preserving only. No bug fixes here — this is purely about removing weight.
- Embedded runtime shader sources are generated automatically into each target's
  Derived Sources directory from `Scripts/metal_embed_inputs.xcfilelist`.

Health read: the codebase is in good shape — no TODO/FIXME cruft, clean module structure.
The weight is in three places: **leftover debug `print()`s**, **dead state/feature-flag paths**
left behind by the recent strip-down, and **duplication between the Mac and visionOS render/audio
paths** that has begun to drift. The two highest-leverage themes are unifying the duplicated
Apple Music adapters and the duplicated animation-interpolation helpers.
